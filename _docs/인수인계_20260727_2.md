## 1. 가장 중요한 것 — 돈 계산 버그

**증상**: 1인당 사례금 만원, 모집인원 2명, 균등분배로 프로젝트를 등록하면 리뷰어 화면에는 1인당 4,250원(85% 수수료 차감 후 8,500원이어야 정상)만 표시됨.

**원인**: `components/builder/new-request/submitProject.ts`가 `incentive_budget` 컬럼에 **1인당 금액**(`feePerEvaluator`)을 그대로 저장했는데, 리뷰어 화면 6곳(`ProjectCardExpandable.tsx`, `ReviewerFeedPage.tsx`, `ReviewerDashboard.tsx`, `LiveActivityTicker.tsx`, `app/evaluator/projects/page.tsx`, `app/api/projects/[id]/distribute/route.ts`)은 전부 이 값을 **전체 풀**로 간주하고 `target_count`로 다시 나누고 있었음 — 결과적으로 두 번 나눠져서 절반 이하로 표시됨.

**수정**: `submitProject.ts`에서 `incentive_budget: feePerEvaluator * evaluatorCount`(총 풀)로 저장하도록 한 줄 변경. 읽는 쪽 6곳은 이미 정상이라 안 건드림. 추가로 `app/evaluator/projects/page.tsx`의 수수료율이 다른 곳과 다르게 `0.8`이었던 것도 `0.85`로 통일.

## 2. 검수 파이프라인 버그 (등록 즉시 공개되던 문제)

**증상**: 크리에이터가 프로젝트를 등록하면 관리자 검수 없이 바로 리뷰어 피드에 노출됨.

**원인**: `types/database.ts`에 `pending_review` 상태가 정의돼 있고 `app/api/admin/requests/[id]/approve|reject`도 이미 완벽하게 구현돼 있었는데, `submitProject.ts`가 등록 시 `status: 'active'`를 바로 넣어버려서 검수 큐 자체를 건너뛰고 있었음(기능은 만들어져 있었으나 연결이 안 된 상태 — 회귀 아님).

**수정**: `submitProject.ts`의 status를 `'pending_review'`로 변경. `components/builder/ProjectDetailPage.tsx`에 "검수 대기중"/"검수 반려됨" 배지 추가해서 크리에이터가 상태를 알 수 있게 함. `app/admin/requests/page.tsx`는 원래부터 `pending_review` 탭이 기본으로 잘 만들어져 있어서 그대로 사용 가능.

## 3. 관리자 패널 — 신규 기능

### 3.1 인사이트 에디터 — 파일 업로드 + 노션 스타일 + 실시간 미리보기
- `insight-covers` Storage 버킷 신설(공개), `app/api/admin/insights/upload/route.ts` — 드래그앤드롭/클릭 업로드.
- `app/admin/insights/page.tsx` 전면 재구성: 3단 레이아웃(글 목록 / 노션 스타일 에디터(큰 제목+블록 본문) / 실시간 미리보기 — 타이핑하는 즉시 실제 상세페이지와 같은 모양으로 반영).

### 3.2 배너 광고 관리 (신규)
- `ad_banners` 테이블(마이그레이션 033) — `placement`('creator_home'|'reviewer_dashboard'), 제목/부제/배지/그라디언트/이미지/버튼문구/버튼링크/노출순서/활성화.
- `banner-images` Storage 버킷 + 업로드 API.
- `app/admin/banners/page.tsx` 신규 — 배치별 배너를 직접 작성·수정·삭제, 그라디언트 또는 이미지 업로드 선택 가능.
- 기존에 컴포넌트에 하드코딩돼 있던 배너 문구(`components/shared/ReviewerBannerCarousel.tsx`, `app/evaluator/dashboard/page.tsx`)를 DB 시드로 그대로 이관하고, 두 컴포넌트 모두 `/api/banners?placement=X`로 fetch하도록 전환(API 실패 시 하드코딩 폴백으로 안전망 유지).
- `/admin` 대시보드에 "배너 광고 관리" 카드 추가.

### 3.3 유저관리 — 이중 역할(크리에이터+리뷰어) 안 뜨던 버그
- `users.role`은 가입 시 한 번만 고정되는 컬럼이라, 크리에이터로 시작한 유저가 나중에 리뷰어로도 활동해도(`project_matches`에 행이 생겨도) `role` 컬럼은 그대로 `'builder'`로 남아있어서 관리자 화면 리뷰어 필터에 절대 안 뜸.
- `app/api/admin/users/route.ts`: `project_matches` 실제 존재 여부로 `is_builder`/`is_reviewer`를 별도 파생해서 함께 응답.
- `app/admin/evaluators/page.tsx`: 필터 로직과 배지 표시를 이 파생 필드 기준으로 변경 — 이제 두 역할 다 있으면 배지 2개가 같이 뜨고 양쪽 필터에 다 걸림.

### 3.4 관리자 승인 로직 재점검
프로젝트 검수 승인/반려(`app/api/admin/requests/[id]/approve|reject`), 유저 정지/재활성/탈퇴(`app/api/admin/users/[id]/status`)를 다시 훑어봤는데, 이미 견고했고 위 2번 버그(검수 우회)가 유일한 실제 결함이었음. 추가로 고칠 것 없음.

## 4. 크리에이터 등록 마법사 개선

- **홈 검색 플로우 순서 버그(중요)**: 검색창에 입력→"검증 시작"을 누르면 "어떻게 검증을 시작할까요?" 모달(`Step0Modal`)을 완전히 건너뛰고 바로 아이템 탐색으로 가던 문제. 더 심각한 건, "아이템 탐색"이든 "아이템이 있어요"든 선택 후 마법사(`/builder/new-request`)에 들어가면 **거기서 또 같은 모달이 재차 뜨는** 이중 질문 버그도 있었음(정확히 사용자가 "뒤늦게 나타난다"고 지적한 증상). `skipIntro` 쿼리 파라미터로 양쪽 다 수정 — `CreatorHome.tsx`가 이제 검색 제출 시 `Step0Modal`을 먼저 띄우고, "아이템 탐색"을 고르면 `ItemDiscoveryFlow`를 열고, 마법사로 넘어갈 땐 항상 `?skipIntro=1`을 붙여서 중복 질문을 막음.
- **카테고리/연령대 3중 불일치**: 등록 마법사(`types.ts`)·홈 아이템찾기(`ItemDiscoveryFlow.tsx`)·리뷰어 필터탭(`evaluator/projects/page.tsx`)이 전부 다른 목록을 하드코딩하고 있었음. 특히 리뷰어 필터는 실제 저장되는 `project.categories` 값과 문자열이 하나도 안 맞아서 **필터를 눌러도 사실상 항상 빈 결과**였던 숨은 버그. `types.ts`의 `CATEGORIES`/`AGE_GROUPS`를 단일 소스로 통일.
- **AI 추천질문 버튼 "먹통" 버그**: `/api/questions/suggest` 실패(로그인 세션/일일한도초과/Claude오류) 시 `if (res.ok)`만 체크하고 실패하면 조용히 아무 반응 없었음 — 401/429/기타 에러 토스트 추가(Standard/Deep 둘 다).
- **복수선택 체크박스** 위치를 옵션 목록 맨 아래에서 "객관식" 라벨 옆으로 이동.
- **질문 설계 스텝 sticky**: 스크롤해도 오른쪽 요약박스/이전·다음 버튼이 화면에 고정되도록 처리.
- **객관식 선지 미리보기(고스트텍스트)**: 질문을 적고 포커스를 벗어나면 AI가 어울리는 선지를 제안해서 빈 칸에 placeholder로 흐리게 미리 보여줌. Tab으로 하나씩 채택하거나 "AI 제안 선지로 채우기" 버튼으로 일괄 적용. 신규 API `app/api/questions/suggest-options/route.ts`.
- **질문 설계 그리드 UI**: 세로로 끝없이 쌓이던 질문 카드를 2열 그리드로 개편.
- **AI 문장 다듬기(신규)**: 문제/솔루션/대안(`Step2Problem.tsx`)과 검증목표/가설(`Step4Light/Standard/Deep.tsx`) 전부에 "AI로 다듬기" 버튼 추가 — Claude haiku로 초안을 완성된 문장으로 다듬어줌. 4개 파일에 중복돼 있던 텍스트에어리어를 `components/builder/new-request/PolishableTextarea.tsx` 하나로 통합. 신규 API `app/api/writing/polish/route.ts`.
- **PDF 드래그앤드롭**: `Step5Attachments.tsx` 문서 첨부 영역에 추가(PDF 아닌 파일은 필터링).
- **[중요] 등록완료 후 남아있던 구 듀얼화면**: `preview`/`preview/complete` 두 페이지가 여전히 옛날 좌우 듀얼패널(`DashboardLayout` + 라운지 우측패널)을 쓰고 있었음 — 등록화면(`new-request/page.tsx`)만 새 단일화면 레이아웃으로 바뀌어 있어서 불일치했던 것. 세 페이지 다 `CreatorLayout`으로 통일하고, 아무 데서도 안 쓰이게 된 `components/shared/DashboardLayout.tsx` 파일 자체를 삭제.
- **프리뷰/리뷰어 화면 질문목록 노출 버그**: `PreviewPage.tsx`의 리뷰어-프리뷰 뷰(`ReviewerView`)가 질문 목록을 그대로 다 보여주고 있었음(리뷰어가 지원 전에 문항을 미리 보면 안 됨) — 제거. 실제 리뷰어 카드(`ProjectCardExpandable.tsx`)는 원래부터 지원 수락 후에만 문항을 보여주고 있어서 문제없었음(확인만).
- **완료됨 컬럼 삭제 경로 누락**: 그리드형 프로젝트 목록의 "완료됨" 컬럼에만 삭제 버튼이 없었음 — 추가.
- **등록완료 화면 버튼 문구**: "대시보드로"(대시보드 자체가 없어짐) → "홈으로"로 변경, 아이콘도 `LayoutDashboard`→`Home`.
- **"제품 체험하기" 링크 깨짐**: `http://` 프로토콜 없이 URL 입력 시 `<a href>`가 상대경로로 해석돼 링크가 깨지던 버그 — 저장 시점(`submitProject.ts`)과 렌더링 시점(`ProjectCardExpandable.tsx`) 양쪽에 `https://` 자동 보정.
- **"1인당 사례금" 명칭**: 확인 결과 이미 정확했음(1인당/총액 둘 다 명확히 표시 중) — 별도 수정 없음.

## 5. 리뷰어 화면

- **파란색 색상 통일**: 리뷰어 화면 전체(9개 파일)에서 제각각이던 파란색을 전부 `#189DF7`로 통일.
- **실시간 동향 티커 안 흐르던 문제**: 코드 버그가 아니라 로컬 개발서버의 낡은 Turbopack 빌드 캐시 때문이었음. `.next` 지우고 재시작하니 정상 동작 확인(운영 배포는 매번 새로 빌드되므로 원래 문제없었을 가능성 높음).

  - **캡처 방지**(`components/evaluator/CaptureGuard.tsx`, 신규): 브라우저에서 스크린샷 자체를 막는 건 불가능(OS 레벨 기능)하므로 억제책 조합 — 반복 워터마크(리뷰어 식별정보 포함, 유출 추적용), 텍스트선택/우클릭/인쇄 차단, **창 포커스 이탈 시(스크린샷 도구 실행 등) 즉시 블러 처리**.
- **카테고리 필터 3중 불일치** — 4번 항목과 동일 건, 리뷰어 필터탭도 함께 수정됨.

## 6. 전체 반응형(모바일) 대응 — 실측 기반

CSS를 추측으로 고치지 않고, Playwright로 375px 뷰포트 렌더링 후 `document.documentElement.scrollWidth - clientWidth`로 가로 오버플로우를 실측하는 방식으로 진행. 발견 즉시 수정 → 재측정 반복.

| 위치 | 문제 | 수정 |
|---|---|---|
| 랜딩 헤더(`Header.tsx`) | pill 헤더의 nav 3개+로고+CTA가 화면 밖으로 밀려 CTA 버튼이 잘림 | sm 미만에서 nav 링크 숨김, 패딩/폰트 축소 |
| 리뷰어 유도 탭(`ReviewerPeek.tsx`) | hover 전용 인터랙션이 터치에서 절대 안 펼쳐지면서 히어로와 겹침 | md 미만에서 숨김 |
| 히어로 CTA(`HeroSection.tsx`) | 버튼 텍스트가 단어 중간에서 줄바꿈 | `break-keep`, 반응형 패딩 |
| 리뷰어 대시보드 헤딩 | `flex` 처리로 "OOO님을 위해..." 문구가 이상하게 끊김 | flex 제거, `break-keep` |
| **크리에이터 프로젝트 화면**(`ProjectsWorkspace.tsx`) | 좌측 고정폭(180px) 사이드바 때문에 본문이 좁아져 글자가 **한 글자씩 세로로 줄바꿈**되는 심각한 버그 | md 미만에서 상단 가로 탭으로 전환, 통계 카드 1열 |
| 공용 푸터(`Footer.tsx`) | 고정 패딩(px-16)+justify-between으로 좁은 화면에서 링크 텍스트가 한 글자씩 끊김 | 반응형 패딩+`flex-wrap` |
